# by Yahoo when many agents pile up on the same ticker.

# - tavily-python is used when TAVILY_API_KEY is set (free tier: 1k/mo)
# - ddgs (DuckDuckGo) is the no-key fallback
# - curated fixture is the final fallback if both live backends fail

ddgs>=6.0

# deepagents is the "agent harness" from LangChain: built-in planning

# orchestrate multi-step claim-tracking research across SEC EDGAR +
# Tavily historical news. beautifulsoup4 is needed for robust HTML->
# text on SEC filings (fallback is a regex stripper).
deepagents>=0.5,<1
beautifulsoup4>=4.12

# Indian NSE/BSE deep-research path (src/agents/workers/_indian_filings.py).
